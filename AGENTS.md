# AGENTS.md

## About the project

My project is called Explore Bosnia. It is a website where people can discover places to visit in Bosnia and Herzegovina.

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## Project structure

- `frontend/` contains the frontend files.
- `backend/` is for the backend.
- `docs/` contains project documentation and the ER diagram.

## Development rules

- Keep the project organized.
- Make sure the website works on different screen sizes.
- Check that navigation works correctly.
- Do not upload passwords or secret files to GitHub.
- Update the README when needed.
