# Explore Bosnia – Discover the Beauty of Bosnia and Herzegovina

## About the Project
Explore Bosnia is a web application designed to help users discover beautiful places in Bosnia and Herzegovina. The platform will provide information about destinations, categories, reviews, and favorite places.

## Project Goals
- Help users discover tourist destinations in Bosnia and Herzegovina.
- Organize destinations into different categories.
- Allow users to review and rate destinations.
- Allow users to save their favorite places.

## Technologies
- HTML
- CSS
- JavaScript
- PHP (planned for the backend)
- MySQL (planned for the database)

## Project Structure
- `frontend/` – frontend files and user interface.
- `backend/` – backend application structure.
- `docs/` – project documentation and database ER diagram.

## Database Design
The planned database includes the following entities:
- USER
- DESTINATION
- REVIEW
- FAVORITE
- CATEGORY
- DESTINATION_CATEGORY

The draft Entity-Relationship Diagram (ERD) is available in `docs/erd.png`.

## Current Progress
- Initial project structure created.
- Static frontend and SPA navigation implemented.
- Draft database schema and ER diagram created.
