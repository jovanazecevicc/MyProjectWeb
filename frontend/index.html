About Explore Bosnia

Discover the beauty of Bosnia and Herzegovina.

Explore Bosnia is a tourism website concept designed to help visitors discover destinations, cultural landmarks and natural attractions throughout Bosnia and Herzegovina.

The project presents destination information in a clear and accessible way. Future versions can include user accounts, reviews and saved favourite places.

This version is a static frontend prototype created for a Web Programming project. Backend and database functionality will be developed later.
